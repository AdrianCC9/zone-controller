# Project working rules

- Configuration is authoritative for point definitions, thresholds and timing.
- Default runs must be simulation or monitoring only; physical output requires a
  commissioned mapping and deliberate operator enablement.
- Do not drive furnace W/Y/G calls. Keep constructed controls within the source
  guide's low-voltage scope.
- Quality and freshness accompany every measurement. Safety outranks overrides.
- Never store camera frames or fabricate commissioning evidence and measured results.
- Update sequence and deficiency documents with behavior or acceptance changes.
- Run pytest, ruff, configuration validation and a seven-day simulation for control changes.
